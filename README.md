# GoalFlow — White Mobile App

A responsive, white-theme productivity app with goals, daily tasks, flexible Mini/Plus/Elite habits, wellbeing check-ins, monthly reviews, ideas and JSON backup.

## Run locally
Open `index.html` in a browser. Installing as an app and offline support require hosting over HTTPS (GitHub Pages works).

## Publish the updated app on GitHub Pages
1. Extract this ZIP on your laptop.
2. Open your existing GitHub repository `goalflow-app`.
3. Choose **Add file → Upload files**.
4. Upload/replace all files in this folder, including `index.html`, `manifest.json`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, and `README.md`. Upload the files themselves, not the outer folder.
5. Commit the changes to the `main` branch. Keep GitHub Pages set to `main` and `/(root)`.
6. Open `https://collegeajaykumar17-cmd.github.io/goalflow-app/` and refresh.

## Install on Android
1. Open the published link in Chrome.
2. Open Chrome's three-dot menu. Tap **Install app** or **Add to Home screen** (wording can vary).
3. Confirm, then launch GoalFlow from your home screen.

If the install option does not appear immediately, wait for the site to finish updating, refresh the page, and revisit it. PWA installation support varies by browser/device.

## Data and privacy
App data is stored locally in the browser on the device. It does not automatically sync between laptop and mobile. Use **Export my data (JSON)** in Wellbeing & review to make a backup before clearing browser data or changing devices.
